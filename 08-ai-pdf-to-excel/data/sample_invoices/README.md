# SAMPLE / SYNTHETIC invoices

Every PDF in this folder was generated by `src/make_samples.py` for a portfolio project. They are **not real invoices**: suppliers, buyer, tax IDs (all starting with zeros) and amounts are invented, and each page is watermarked "SAMPLE / SYNTHETIC".

`answer_key.csv` and `answer_key_lines.csv` hold the true values, used only to measure extraction accuracy. The column `planted_issue` lists the problems added on purpose (wrong total, wrong line amount, due date before issue date, scanned image without text, duplicate invoice).
