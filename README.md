# Data Portfolio · Marlon Jiménez Valencia

Eight sample data projects, each built with public data, from the raw download to the deliverable a client
receives: an Excel report, an interactive dashboard, a clean dataset, a verified lead list, a statistical report,
a predictive model, a research brief and an automation pipeline. Every project rebuilds with one command, checks
its own output, and documents its sources and licences.

**Website:** <https://marlonjimenezv.github.io/data-portfolio/>

## Principles

- **Real, public data only**, with source and licence cited. The one exception is project 08, whose invoices are
  generated and marked "SAMPLE / SYNTHETIC" in every file.
- **Organisations, not people.** Personal names, ID numbers, e-mails and phones are never requested or are removed;
  automatic checks fail the build if they appear.
- **Respectful collection.** Official APIs and open-data portals first; website checks read robots.txt, identify
  themselves and pause between requests.
- **No invented results.** Every number in the texts is computed from the data by the project's code. These are
  sample projects, not client engagements.

## Reproduce

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python 01-excel-kpi-report/run.py     # or any other project's run.py
.venv/bin/python run_all.py                      # all eight projects, then the website (docs/)
```

System tools used by some projects: LibreOffice (Excel recalculation and screenshots), Node.js with Playwright and
Chromium (dashboard tests and screenshots), poppler (`pdftoppm`) and pandoc.

## Repository layout

```

common/              shared style (palette, Inter font), Upwork image helpers, LibreOffice and browser tools
docs/                GitHub Pages site: landing page, live dashboard, survey and churn reports

requirements.txt     pinned Python packages
```
